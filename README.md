# Money Judgement

Hệ thống quản lý nợ chi tiêu chung nhóm (nội bộ công ty/bạn bè), tương tự Splitwise.

## Cấu trúc dự án

- **`front-end/`**: Ứng dụng Web viết bằng Next.js 16 (App Router), TypeScript, Tailwind CSS, React Query.
- **`back-end/`**: Hệ thống Microservices với FastAPI, PostgreSQL, MinIO kết nối qua API Gateway / BFF.
